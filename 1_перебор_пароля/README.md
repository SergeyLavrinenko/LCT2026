# Перебор пароля (энкодер + камера)

**Метод.** 
ESP32 **эмулирует
энкодер** (линии A/B и кнопку), а `crack.py` с ПК управляет по Serial esp32 и по кадру с
**камеры** читает реакцию.

**Пины ESP32** (в прошивке): A=GPIO25, B=GPIO26, кнопка=GPIO27, RESET цели=GPIO32,
вход WS2812=GPIO34.

## Файлы
- `encoder_bruteforce_v3.ino` — прошивка ESP32; принимает команды от `crack.py`,
  щёлкает энкодер, докладывает `OK*`/вердикт.
- `crack.py` — главный: гоняет перебор, шлёт коды в ESP, читает цифру с камеры.
  - `detect_digit.py`, `mark_leds.py`, `grab.py` — распознавание.
  - `led_coords.json` — координаты LED/сегментов для камеры.
  - `marked.jpg`, `detected.jpg` — опорные кадры (разметка).
- `crack.log`, `crack_log.jsonl` — логи прогона; `crack_progress.txt` — для учета, какие коды уже проверялись (чтобы не проверять их снова).
- `monitor.py` — ручной Serial-монитор ESP.

## Как использовать
1. Залить `encoder_bruteforce_v3.ino` в ESP32.
2. Навести камеру на индикатор и жестко зафиксировать (чтобы положение платы в кадре не менялось), при необходимости обновить `led_coords.json`.
3. Запуск перебора:
   ```
   python3 crack.py --range 0000 9999      # весь диапазон (можно с резюме)
   python3 crack.py --code 2266            # проверить один код
   python3 crack.py --center 5000          # веером от центра
   ```
