# Дамп и разбор прошивки (внешняя SPI-флешка W25Q16, 2 МБ)

**Метод.** Прошивка лежит во внешней QSPI-флешке. Снять её можно
двумя способами:

1. **ESP32 как master SPI.** Подключаемся к флешке в одноканальном режиме SPI, ESP читает чип по SPI.
   Пины ESP: CS=GPIO5, SCK=18, MISO=19, MOSI=23, RUN цели=27.
   *(На RP2040-Zero кнопка BOOT висит на /CS — не жать при дампе.)*
2. **J-Link по SWD.** Работает, только когда крутится обычная прошивка;
   Выполнено чтение через программу JMem с адреса `0x10000000`.

## Файлы
- `src/main.ino` + `platformio.ini` — прошивка ESP32-программатора (способ 1).
- `dump_flash.py` — хост-приёмник: шлёт команду дампа, ловит поток, сверяет CRC32.
- `dump.jlink` — скрипт J-Link Commander (способ 2).
- `firmware.bin` — **эталонный чистый дамп 2 МБ** (MD5 011cd65d…), сверен 3 способами.
- `dump.asm` — аннотированный дизассемблер.

Верхний 1 МБ (`0x100000+`) — зашифрованные данные (данные на флешке).

## Как использовать
- Способ 1: `pio run -t upload` (из этой папки), затем
  `python3 dump_flash.py -o firmware.bin` (весь чип).
- Способ 2: `JLinkExe -CommanderScript dump.jlink -NoGui 1` (или GUI JMem, адрес
  `0x10000000`, длина `0x200000`).
