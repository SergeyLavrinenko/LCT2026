# Флешка и приз (после верного кода 2266)

**Метод.** При вводе правильного пароля цель поднимается по USB как флешка (FAT)
с архивом-призом. `fat.img` — образ этого накопителя. Внутри — матрёшка:
`YOUR_PRIZE.zip` = **1337 вложенных запароленных архивов**, где
**пароль каждого слоя это его номер** (`layer_42.zip` — пароль `42`).

## Файлы
- `fat.img` — образ появившегося FAT-накопителя.
- `YOUR_PRIZE.zip` — `readme.txt` (подсказка) + `layers.zip` (сама матрёшка).
- `PRIZE_prize.html` — приз.

## Как использовать
Распаковать матрёшку скриптом (пароль = номер слоя):
```
unzip YOUR_PRIZE.zip
f=layers.zip
for i in $(seq 1 1337); do
  unzip -o -P "$i" "$f" >/dev/null || break
  f="layer_$i.zip"            # имя следующего слоя (уточнить по факту)
done
```
